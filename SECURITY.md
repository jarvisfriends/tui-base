# Security Policy

## Supported versions

Only the latest tagged release and the current `main` branch receive security
fixes.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository
(Security → Report a vulnerability) rather than opening a public issue.
You should receive an initial response within a week.

tui-base is designed to be air-gap safe: no telemetry, no network calls home.
If you find code that violates that promise, report it the same way.
